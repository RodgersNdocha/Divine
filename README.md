# Divine Budget Entertainment Website

Official website for **Divine Budget Entertainment** — a premier events & entertainment company in Kenya specializing in Sound & PA systems for hire, Videography & Livestreaming, Photography, DJ & MC services, Event Coverage, and Trainings.

## Features
- **Modern Multi-Page Architecture**:
  - `index.html`: Comprehensive showcase homepage with hero, track record numbers, services overview, curated work gallery, about us, client logos, testimonials, quote form, and contact info.
  - `services.html`: Detailed service breakdown across all 6 core offerings and covered event types.
  - `work.html`: Real event photography gallery with click-to-enlarge lightbox modal.
  - `about.html`: Company mission, values, and crew showcase.
  - `clients.html`: Partner logos in full brand colour and client testimonials.
  - `contact.html`: Direct phone, WhatsApp, Instagram links, and an interactive WhatsApp booking form.
- **WhatsApp Chat Popup Widget**: Floating interactive WhatsApp popup and trigger button linking directly to `+254 725 027 263`.
- **Responsive Design**: Fast, lightweight, pure HTML/CSS/JS without bulky frameworks.
- **Typography**: Oswald (Display/Headings) and Work Sans (Body).

## Running Locally
You can serve the static site using any local HTTP server:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080/`.
